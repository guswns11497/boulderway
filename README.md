# BoulderWay Beta v1.3 — 백업 버튼 수정

## 수정
- MY 화면의 `JSON 백업 내려받기`, `백업 내용 직접 복사하기`가 동작하지 않았던 조건문 순서 오류 수정.
- 문제를 선택하지 않은 상태에서도 백업 기능 실행.
- 다운로드가 막혀도 `백업 내용 직접 복사하기`에서 JSON 텍스트를 펼쳐 메모장에 저장 가능.

## 안전하게 업데이트하기
기존 기록이 들어 있는 웹주소의 localStorage를 지우지 마세요. GitHub Pages에 `index.html`을 새 버전으로 덮어쓰면, 같은 브라우저와 같은 도메인에서 기존 기록을 유지하면서 백업 버튼을 이용할 수 있습니다. 새로운 폴더의 `file://` HTML이나 다른 브라우저에서는 저장소가 달라 기존 기록이 안 보일 수 있습니다. 기존 파일을 먼저 백업하고 기록이 그대로 있는지 확인하세요.
